ECS / OCS
Start the game and press ‘P’ to pause. Type “NCC-1701” and then any key except ‘P’. The screen will flash blue several times and you now have unlimited lives. Press ‘P’ to unpause and return to the game.
When you destroy a goosecopter, it will split into 3 power up icons which cycle between 4 different symbols. Each time you shoot the icon twice it will change to a new symbol. If you shoot it 100 times (so it changes symbols 50 times) it will be replaced with a yellow star. If you collect the star, you will gain super fast 8 way fire!
